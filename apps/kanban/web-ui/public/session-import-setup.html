Set up session history import

Kanban imports an exact Codex session into a registered desk through the host's local import service. A new installation needs the portable desk store, reviewed catalog, and exact-session admission prepared before an import can run. History alone never grants a role or desk admission.

Host configuration

  1. Install the kp-agent-session-import executable on the Kanban host.
  2. Create a private ops.desk-memory.local.v1 config with absolute paths to the state store and reviewed catalog. Initialize the desk store and admit the exact host session through the portable desk CLI.
  3. Start Kanban with KANBAN_SESSION_IMPORT_EXECUTABLE set to the executable's absolute path and KANBAN_SESSION_IMPORT_CONFIG set to that private config's absolute path.

Kanban checks those host paths. The chat dialog cannot run a browser-supplied command or create a desk binding. Use the registered desk menu in the dialog to choose the reviewed destination.

Choose a source

If this Kanban task has an observed Codex native session binding, the dialog fills in its exact session file and ID. Otherwise, supply an absolute native JSONL file path and its session ID. Preview verifies the ID against the file's native metadata; a working directory or transcript text is not an identity.

Choose Full session for the reviewed snapshot or Current turn onward for the latest trustworthy native user turn and future turns. The preview shows coverage and counts before you approve. You can stop future capture from the job status panel.
