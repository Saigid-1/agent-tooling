# Portable desk-memory entry

This host uses the independent agent-tooling memory service. Older charter/entry
pages may still describe the retired legacy graph CLI; retain their role/doctrine
content, but do not execute their `desk_memory_cli.py` bootstrap, claim, write or
retirement commands to establish portable memory access.

A directory default, historical run, claim note or board card does not admit this
session. The current SessionStart receipt and `memory.connection_status` report
whether its exact host ID is admitted. If not ready, report that ID and the intended
desk to the operator. Tool discovery remains available but grants no authority.

After admission, use `memory.search` for historical recall and `memory.propose` for
cited authored handoffs. A proposal is not an accepted ruling. Resume preserves the
same admitted host ID; a new ID needs its own explicit selection. Multiple sessions
may occupy the same desk. SessionEnd observes an end; it does not revoke admission.

Follow the repository's current CLAUDE.md/AGENTS.md for delivery and scope. Desk
memory admission does not authorize merges, releases, dispatch, or unrelated tools.
The retired `ops-gateway` is not required for these memory operations.
